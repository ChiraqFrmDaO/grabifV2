Authentication

All API endpoints require authentication using a Bearer token. Include your API token in the Authorization header:

Authorization: Bearer YOUR_API_TOKEN

You can generate and manage your API token in the dashboard.

Base URL

https://yourdomain.com/api/v1

Endpoints

Create Tracker

POST /create-tracker

Create a new tracking link programmatically.

POST /api/v1/create-tracker
Authorization: Bearer YOUR_TOKEN
Content-Type: application/json

{
  "name": "My Tracker",
  "destination_url": "https://example.com",
  "discord_webhook": "https://discord.com/api/webhooks/...",
  "telegram_webhook": "https://api.telegram.org/bot.../sendMessage",
  "custom_webhook": "https://yourserver.com/webhook",
  "filter_bots": true,
  "filter_search_engines": true,
  "filter_social_media": true,
  "alternative_domain": "https://alternative-domain.com",
  "custom_landing_page": "https://yourpage.com/custom"
}
td>
Field Type Required Description
name string Required Name of the tracker
destination_url string Required Target URL to redirect to (must be https://)
discord_webhook string Optional Discord webhook URL for notifications
telegram_webhookstring Optional Telegram bot URL for notifications
custom_webhook string Optional Custom webhook URL for notifications
filter_bots boolean Optional Filter bot traffic (default: true)
filter_search_engines boolean Optional Filter search engine crawlers (default: true)
filter_social_media boolean Optional Filter social media crawlers (default: true)
alternative_domain string Optional Alternative domain for URL masking
custom_landing_page string Optional Custom landing page URL

Response:

{
  "success": true,
  "message": "Tracker created successfully",
  "data": {
    "tracker_id": "abc123",
    "tracking_link": "https://yourdomain.com/abc123",
    "management_link": "https://yourdomain.com/manage/xyz789"
  }
}

Get Logs

GET /logs/:tracker_id

Retrieve logs for a specific tracker.

GET /api/v1/logs/abc123
Authorization: Bearer YOUR_API_TOKEN
Parameter Type Required Description
tracker_id string Required The tracker ID to retrieve logs for

Query Parameters:

Parameter Type Default Description
limit integer 100 Maximum number of logs to return
offset integer 0 Offset for pagination

Response:

Rate Limiting

API endpoints are rate limited to prevent abuse:

  • 100 requests per minute per IP
  • Authenticated users have higher limits

Error Codes

Code Description
200 Success
400 Bad Request - Invalid input
401 Unauthorized - Invalid or missing API token
403 Forbidden - Access denied to tracker
404 Not Found - Tracker not found
429 Too Many Requests - Rate limit exceeded
500 Internal Server Error

Examples

JavaScript (Node.js)

const response = await fetch('https://yourdomain.com/api/v1/create-tracker', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_API_TOKEN',
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({
    name: 'Test Tracker',
    destination_url: 'https://example.com'
  })
});

const data = await response.json();
console.log(data);

Python

import requests

headers = {
    'Authorization': 'Bearer YOUR_API_TOKEN',
    'Content-Type': 'application/json'
}

data = {
    'name': 'Test Tracker',
    'destination_url': 'https://example.com'
}

response = requests.post('https://yourdomain.com/api/v1/create-tracker', 
                         headers=headers, json=data)
print(response.json())

cURL

curl -X POST https://yourdomain.com/api/v1/create-tracker \
  -H "Authorization: Bearer YOUR_API_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Test Tracker","destination_url":"https://example.com"}'
⚠️ Security Note: Never share your API token publicly. Treat it like a password. Regenerate it if compromised.
